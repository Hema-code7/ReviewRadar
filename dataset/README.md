
# ReviewRadar - Dataset

This folder contains datasets used for training and evaluating the ReviewRadar machine learning models.

## Planned Datasets

### 1. Human-Written Reviews
Reviews written by people.

### 2. AI-Generated Reviews
Reviews generated using AI language models.

## Dataset Preparation

The datasets will be:
- Inspected for quality and missing values.
- Cleaned and preprocessed.
- Labelled appropriately.
- Split into training and testing sets.

## Classification Tasks

1. Human-written vs AI-generated review text.
2. Genuine vs deceptive reviews (future extension).

## Important Note

AI-generated text does not automatically mean a review is fake or deceptive.

Dataset sources, licences and preprocessing details will be documented before model training.
